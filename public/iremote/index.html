IRemote

Your iPhone or iPad, now a keyboard and trackpad for your Mac.

Requires iOS or iPadOS 17 or later and macOS 14 or later. Bluetooth provides direct input; the Mac app and local network add screen preview and input integrations.

Bluetooth direct control

In IRemote, choose Bluetooth and select your Mac. Complete any system pairing request, then explicitly start control. Existing OS trust can mean no new pairing prompt. Forgetting a Mac in IRemote removes the app record, not the OS pairing. Bluetooth does not provide screen preview or Mac input-source reporting.

Mac app connection

  1. Open IRemote on the Mac and allow Local Network access when prompted. Use the app’s control-permission button to open the appropriate macOS settings.
  2. Choose “Pair a device” on the Mac, then scan its QR code in IRemote on your iPhone or iPad. Manual code entry is also available.
  3. Approve the connection on the Mac. “Remember & allow” saves the device for automatic reconnection.

Screen preview

Preview is optional and starts only when requested. Allow Screen Recording on the Mac, then start preview. Choose the area near the pointer or a full display, select a monitor, and zoom or pan on the mobile device. Stopping preview stops capture.

Connection help

Use the current IRemote apps on both devices. Scan the QR code on the Mac. On that Mac, choose Remember & allow or Allow once.

  • Keep both apps open and use the same local network. Guest networks may block device-to-device communication.
  • If control is paused, resume it on the Mac. Use the control-permission button in the Mac app if input is unavailable.
  • Closing the Mac window keeps the connection alive. Use the menu bar to reopen the window or quit.
  • If preview cannot start, check Screen Recording permission. If macOS requests a restart, restart the companion, reconnect, and start preview again.
  • To revoke access, forget the device on the Mac. To remove both saved records, forget the relationship on both devices.

아이폰·아이패드로 Mac 조작

Bluetooth는 Mac 앱 없이 기본 입력을 제공하며, Mac에서 IRemote를 열면 같은 로컬 네트워크에서 화면 미리보기와 입력 연동을 사용할 수 있습니다. Mac의 QR 코드를 아이폰·아이패드에서 스캔한 뒤 Mac에서 승인하면 조작할 수 있습니다. 입력이 안 되면 Mac 앱의 제어 권한 버튼을 눌러 시스템 설정을 확인하세요. 화면 미리보기를 사용하려면 화면 기록 권한도 필요합니다.

연결이 안 되면 로컬 네트워크 권한과 같은 네트워크인지 확인하세요. 공유기 게스트 네트워크는 기기 사이의 연결을 막을 수 있습니다. Mac 창을 닫아도 연결은 유지되며 메뉴 막대에서 다시 열거나 종료할 수 있습니다.
