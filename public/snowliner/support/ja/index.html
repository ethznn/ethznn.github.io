Snowliner サポート

最初のターンから記録のバックアップまで。滑走に必要なヘルプをご案内します。

雪と風、自分のペースで

音楽を流さず、雪を削る音や風に耳を澄ませて滑れます。自分の音楽を聴きたいときは、別のアプリで再生してからSnowlinerを開いてください。

ゲームの音が音楽より大きい場合は、Snowlinerの設定で音量を下げてください。iPhone側面のボタンは再生音量全体を調整します。

音楽はお使いの音楽アプリで再生します。Snowlinerは楽曲や音楽配信サービスを提供していません。

最初の滑走

ホームから最初のスロープに挑戦しましょう。サニースロープで銀メダルを取ると次のコースが開きます。フリーライドは目標点数のない別モードです。操作に慣れたい場合は任意の操作練習を選べます。一時停止からスキップや現在のステップのやり直しができ、設定 → ヘルプから再開できます。

傾き操作と前足

端末を横向きに楽に持ち、準備ができたら出発します。片側を少し下げるとそちらにターンします。前に傾けると姿勢を低くし、後ろに傾け続けると減速します。前後の荷重操作をオフにした場合はブレーキボタンを使います。安定した滑走中に端末の上部を体の方へ軽く引いて戻すと前足を切り替えられます。傾き操作では画面の左右を押してもターン入力は加わりません。

タッチと基準姿勢

傾き操作が難しい場合は設定 → 操作でタッチを選びます。パッドの左右でターン、上で姿勢を低くし、下で減速します。180°ボタンで前足を切り替えます。基準がずれたら姿勢を再調整してください。アプリを離れたり画面の向きを変えたりすると滑走を止め、再び準備します。

メダルとコース

通常コース11か所に銅・銀・金メダルがあり、合計33個です。コースメダルと新しいコースはラインチャレンジで獲得します。完走で銅メダル、表示された目標点数と転倒2回以下で銀メダル、より高い目標点数と転倒0回で金メダルです。同じ1回の完走で条件を満たす必要があります。フリーライドではコースメダルを獲得しませんが、記録メダルの完走回数に含まれます。正確な目標点数と開放されるコースはチャレンジ画面で確認できます。

ゲートとボーナス

番号付きゲートの地面の円を通ると基本100点です。順番に続けて集めると連続ボーナスが25点ずつ増え、ゲートごとに最大100点が加わります。1区間のゲート4個をすべて集めると、さらに400点です。取り逃しや転倒で連続は切れますが、獲得済みの点数は残ります。結果画面で内訳を確認できます。同じラインの再挑戦は同じ配置です。新たにチャレンジを選ぶと配置が変わります。最高記録の比較は同じラインが対象です。

ミニマップ・転倒・ゴール

矢印は現在地と移動方向、円はスタート、旗はゴールです。薄い線はゴール後の区間です。ゴールを越えた後に転倒するか、表示速度が0になると自動で結果に進み、記録を保存します。ゴール前に転倒したら立ち上がるまで待ち、操作を離すか中立姿勢に戻して復帰します。

バランス円の見方

点は端末の角度そのものではなく、ゲーム内の体の中心が支えられる姿勢からずれた方向を表します。深く傾けても安定したターンなら点は中央付近にあります。短い軌跡は直前の動き、縁の印はずれが続く方向で、緑は中心へ戻る動きです。左右と前後の両方を表示します。エッジの滑りや急な切り返しは別の警告になる場合があります。実際の身体のバランスを測定・診断するものではありません。

メダルコレクションと記録

最近のライン24件を保存し、そのうち最大8件をお気に入りとして自動整理から保護できます。古い通常記録から整理します。ラインを削除してもメダルと最高記録は残ります。ホームまたはマイ記録 → メダルコレクションで獲得済み・未獲得のメダルと条件を確認できます。コースメダル6個・12個でボードの色が開き、33個すべてで記念カードを見られます。外見による性能差はありません。獲得済みのメダルと開放済みコースは維持されます。

記録メダル

通常コースの完走1・5・10・25・50・100回と、累計チャレンジ得点1,000・5,000・10,000・25,000・50,000・100,000点で計12個を集められます。フリーライドとチャレンジの完走を合算し、操作練習は除外します。得点は完走したチャレンジのみ加算します。ラインの削除や自動整理後も累計記録は残ります。以前の得点は保存済みのラインから合算し、既存の完走回数は維持します。記録メダルはコースやボードの色の開放には含まれません。

バックアップと保存

設定 → ヘルプ → 記録バックアップからファイルを保存・復元できます。メダル・開放済みコース・ライン記録を含み、操作・音・画面の設定は含みません。復元前に内容を確認でき、最後のファイル復元直前の記録に戻すこともできます。テストビルドでは同じプレイモードのバックアップだけを復元できます。アカウントや自動クラウド同期はありません。端末変更やアプリ削除の前にアプリ外へファイルを保存してください。保存に失敗したら空き容量を増やし、再保存してください。破損時の自動復旧では最後の滑走が失われる場合があります。

お問い合わせ

設定 → ヘルプ → お問い合わせ・アプリ情報から prxyeo@gmail.com に連絡できます。機種、iOS・アプリのバージョン、問題が起きた手順をお知らせください。実際のスキー場の地形や人物の位置情報は使用しません。

マイゴースト

ホームの全コースで、解放後にタイムランを選べます。操作練習は別です。準備画面に表示される必須ゲートをすべて通過すると、初めての有効な完走と、その後の自己ベストを自動保存します。準備・一時停止画面で表示を切り替えられます。非表示でもベスト記録は保存します。

コース・ボード・滑走ルールが一致する記録だけ再生します。ゴールラインで計測を終了し、準備と一時停止は除外、転倒と復帰時間は含めます。

ベスト記録とゴーストはコース・ボードごとに保存し、同じ配置でのみ比較します。ゴーストは端末内に保存し、アルバムを削除しても残ります。設定 → ヘルプ → ゴーストファイルの削除で消去できます。メダルとベスト記録は残ります。手動バックアップには再生ファイルを含みません。削除や機種変更後はベスト更新で再保存します。過去のラインからは生成できません。

ゲートの縁

足元に見える円全体が通過範囲で、縁にはわずかな判定の余裕があります。高速でもフレーム間の移動経路で判定します。タイムランでは円全体を通り過ぎてから未通過が確定します。引き返しや復帰位置への移動では未通過ゲートを埋められません。配置変更前の記録は残し、新配置のベスト・ゴーストとは別に扱います。近いゴーストも輪郭を保ち、自分のボーダーを隠す場合だけ胴体を薄くします。

バランスの回復

左右に大きく繰り返し傾けると、ライダーの体に揺れが残ります。危険表示は回復の機会を知らせるもので、時間がたつと必ず転倒するタイマーではありません。スマートフォンを出発時の姿勢に戻して保つと、揺れが収まります。表示された方向に小さく補正するか減速すると、より早く回復できます。傾けたまま静止するとターン入力が続くため、中立を保つこととは異なります。すでに体が支えを失い転倒が始まった場合、その転倒は取り消せません。大きく左右に振り返すのではなく、中立に戻して少し待ちましょう。

雪と風、そして自分の音楽

音楽を流さずに、風や雪を削る音に耳を澄ませて滑ることもできます。自分の音楽を聴きたいときは、別の音楽アプリで再生してからSnowlinerを開いてください。ゲームの音量は設定で個別に調整でき、他のアプリの音楽の音量は変わりません。Snowlinerは楽曲や音楽配信サービスを提供していません。
