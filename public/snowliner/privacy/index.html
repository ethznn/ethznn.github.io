Snowliner 1.1.0 이상에 적용됩니다. 이전 1.0.x에는 광고 SDK가 없습니다. 별도 계정은 필요하지 않으며 주행 기록과 기기 움직임은 기기에 보관합니다. 선택형 보상 광고에는 Google AdMob을, 구매와 구매 복원에는 Apple StoreKit을 사용합니다.

기기에서 처리하는 정보

기울임 조작을 위해 기기의 움직임 값을 사용합니다. 주행 시간, 턴·낙상, 게임 속 가상 이동 경로, 도전과 조작·음량·언어 설정은 기기에 저장합니다. 실제 GPS 위치, 연락처, 카메라, 마이크, 사진 라이브러리 접근을 요청하지 않습니다.

공유

사용자가 공유를 선택한 경우에만 게임 이미지가 iOS 공유 시트로 전달됩니다. 이후 선택한 앱이나 서비스의 처리는 해당 서비스의 정책을 따릅니다. 공유용 임시 이미지는 다음 공유 시 교체되며 운영체제가 정리할 수 있습니다.

저장과 삭제

최근 라인은 최대 24개, 즐겨찾기는 그중 최대 8개입니다. 앨범에서 개별 라인을 삭제할 수 있으며 도전·최고 기록은 별도로 유지됩니다. 삭제 내용은 다음 저장에도 반영됩니다. 복구용 백업에는 직전 저장 상태가 남을 수 있습니다. 앱을 삭제하면 앱 안의 기록과 설정을 제거할 수 있습니다. 운영체제의 기기 백업은 사용자의 설정과 Apple 정책에 따릅니다. 별도 클라우드 동기화는 제공하지 않습니다.

구매와 문의

앱 구매·결제·환불은 Apple이 처리하며 개발자는 카드 정보를 받지 않습니다. 문의는 App Store의 앱 지원 페이지를 이용하세요. 이메일 문의 시 사용자가 직접 보낸 연락처와 내용은 문의 응대에 사용될 수 있습니다.

개발·테스트 빌드

개발 빌드는 문제 확인용 움직임·프레임 기록을 기기에 임시 보관할 수 있습니다. 자동 전송하지 않으며 일반 배포 빌드에서는 이 진단 기록을 생성하지 않습니다.

정책 변경

정보 처리 방식이 바뀌면 앱과 지원 페이지의 정책을 함께 갱신합니다.

파일 백업과 복원

기록 백업은 사용자가 선택한 경우에만 파일 앱으로 내보냅니다. 파일에는 메달·열린 코스·게임 속 경로와 기록이 포함됩니다. 선택한 저장 위치가 클라우드 서비스라면 해당 서비스의 정책이 적용됩니다. 앱 삭제로 앱 밖의 백업 파일이 지워지지는 않습니다. 복원 시 기존 기록을 교체하며, 마지막 파일 복원 직전의 기록은 기기에 별도로 보관합니다. 임시 내보내기 파일은 다음 내보내기 때 교체되고 가져온 임시 파일은 확인 후 삭제합니다.

고스트 재생 기록

지원하는 타임런의 첫 유효 완주와 더 빠른 최고 기록은 고스트 표시 여부와 관계없이 시각·게임 속 위치·자세를 기기에 저장합니다. 기기 센서 원시값이나 실제 위치는 저장하지 않습니다. 재생 파일은 기록당 1MiB, 전체 32MiB·21개 이하로 제한하며, 설정 → 도움말에서 고스트 파일만 삭제할 수 있습니다. 앨범 삭제와 별도로 관리되고 수동 진행 백업에는 포함되지 않습니다. 자동 전송·친구 공유 기능은 없습니다.

선택형 보상 광고

광고를 요청하면 Google Mobile Ads와 User Messaging Platform이 IP 기반 대략적 위치, 기기 식별자, 광고 노출·상호작용, 오류·성능 정보를 광고 제공, 부정 이용 방지, 동의 처리와 측정 목적으로 처리할 수 있습니다. Snowliner는 비개인화 광고를 요청하고 게시자 자사 식별자를 끄며 앱 간 추적 권한을 요청하지 않습니다. 비개인화 광고도 데이터가 수집되지 않는다는 뜻은 아닙니다. 필요한 동의 화면은 광고 전에 표시하며, 변경 가능한 경우 설정 → 도움말 → 광고 개인정보 설정에서 선택을 바꿀 수 있습니다. 무제한 구매자는 보상 광고를 볼 필요가 없습니다. Google 개인정보처리방침: https://policies.google.com/privacy

구매 권한과 리프트 잔액

Apple이 기존 앱 구매와 무제한 이용권을 검증합니다. 검증된 구매 상태는 기기에서 처리하며 개발자는 카드 정보를 받지 않습니다. 일일·광고 리프트 잔액과 보상 중복 방지 식별자는 진행 백업과 별도로 기기에 저장합니다. 진행 백업으로 리프트 잔액이나 구매 권한이 이전되지는 않습니다. 같은 Apple 계정에서 구매 복원을 이용하세요. A GROVE 로그인은 필요하지 않습니다.

판매 방식 전환 확인

무료 전환 전에 구매한 이용자를 보호하기 위해 ethznn.github.io에서 공통 출시 정책을 읽습니다. 이 요청에 사용자 식별자, 영수증, 주행 기록은 포함하지 않습니다. 호스팅 제공자는 자체 정책에 따라 IP 주소 등 일반 연결 정보를 처리합니다. GitHub 개인정보처리방침: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement
